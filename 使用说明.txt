学迹 · StudyTrail · 学びのあと 2.11.0

启动 Windows 发布包 StudyTrail-2.11.0-Windows-x64.exe。本地旧目录仍可通过原来的启动方式打开。
在主界面语言选择器切换中文、English、日本語，桌宠和设置同步切换；自己的文字、旧记录与库存保留。

开始学习：在首页选择学习方向和时长，默认 25 分钟，可选 5 / 25 / 50 或自定义 5–240 分钟，下次会记住选择。记录断点：明确点击后截取学习画面，确认位置与下一步，再保存。
桌宠：单击展开对话，拖动移动，右键打开设置。对话 × 只收起面板。关闭主窗口可选择保留桌宠并收起到托盘。
找回桌宠：从首页、伙伴页或托盘显示。游戏模式可用 F7 恢复互动。开机启动、位置、大小、透明度在独立桌宠设置调整。

商城的新工具（永久购买一次）：
观察镜 → 观察异叶，好奇心 +3。
水彩盒 → 选两种颜色制作邮票，创造力 +3。
指南针 → 走相邻格完成迷宫，勇气 +3。
星图 → 接续月相，智慧 +3。
旅行手账 → 记住伙伴的选择，默契 +3。
保温杯 → 安静休息 30 秒，精力 +6、心情 +2。

伙伴页的口袋邮局：花园可直接走，观察镜解锁森林，指南针解锁星空。每次三个小选择，关闭后还能续上。三条路线各有四种天气，共十二张明信片。水彩盒配色会出现在邮票上。
每天每种工具首次成功可成长，邮局每天首次完成可成长；和原有小游戏共用灵感及每日最多六次成长。没有灵感仍可玩，游戏不会计作学习或产生小鱼干。正在专注时先暂停。

应用时间默认安静记录，不要求逐次确认。在「今日 → 应用时间」看今日排行，在「周报 → 每日回顾」看每天各应用时长；应用使用与课表、已记录专注分开展示，不重复计入投入。在「我的」可调整记录设置。暂停后仍能看旧日志；缺失日志的日期无法还原。自动截屏默认关闭，更新保留已有选择。
记账：导航「记账」可添加人民币收入与支出，选择分类、日期和备注，按月查看结余、预算及分类分布，支持编辑、确认删除和 CSV 导出。真实收支与小鱼干独立；记账数据随完整 JSON 备份一起导出、导入。
升级沿用 landing 用户数据目录。退出整个应用后可备份该目录；不要删除旧目录。设置中也可导出 JSON 备份，注意其中可能含 API Key。

本版提供桌面端，不包含安卓端。
