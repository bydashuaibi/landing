着陆 2.10.0 · 每天一点，慢慢做到

启动：双击本目录的「启动着陆.cmd」，或「着陆」文件夹里的 electron.exe。

桌宠交互与独立设置（2.10 新增）：
默认只显示角色和简短状态条。单击角色展开／收起对话，按住拖动搬家，右键或点状态条「≡」打开菜单。
对话上的「×」和「−」都只收起对话，角色保留；右键菜单「隐藏整个桌宠」才会隐藏伙伴。
右键「桌宠设置…」打开独立窗口，首页、伙伴页与系统托盘也有入口；设置即时生效并保存。
外观：大小 60–160%、角色透明度 25–100%、保持置顶、显示桌宠任务栏图标、找回桌宠与更换皮肤。
互动：锁定位置、游戏模式／鼠标穿透、悬停变淡、显示操作提示。对话和设置窗口保持清晰。
鼠标穿透开启后不能点击桌宠，按 F7 或托盘「显示桌宠 / 恢复互动」恢复；F7 被占用时会提示并保留互动。
「找回桌宠」会移到主屏右下并恢复互动，适合切换显示器后使用。
「启动与关闭」可设置开机启动；关闭主窗口建议选「保留桌宠，收起到托盘」，计时和安静记录继续。
选择「退出整个着陆」或托盘「退出着陆」会同时退出桌宠。收起设置窗口不影响角色。
命令行 --pet-settings 打开设置；--desktop-pet 叫回桌宠并恢复互动。旧皮肤、学习、养成和安静记录延用。

Sage Studio 界面与桌面显示（2.9 新增）：
首页采用浅鼠尾草绿背景、森林绿文字与磨砂卡片；左侧开始学习，中间互动伙伴，右侧查看真实的今日专注、计划与连续行动。
点「先学 5 分钟」按当前 Python / PyTorch 方向开始；已有计时时回到当前专注，不另开计时。课程断点、计划和复盘保留在下方。
窄窗口用左上角圆形菜单切换七个页面；后台刷新不会收起菜单。系统减少动态效果时跳过入场动画。
首页、伙伴页与换肤窗口新增「显示到桌面」。旧设置关闭桌宠时，也能直接重新叫出独立悬浮窗口。
换上皮肤会同时显示桌宠；收起着陆主界面后，桌面伙伴仍可开始学习、记断点和切换页面。
隐藏桌宠后可再次点击「显示到桌面」；命令行 --desktop-pet 也能启用并显示。保留现有学习、养成、皮肤库和安静记录设置。

换肤窗口与新玩法（2.8 新增）：
首页伙伴、伙伴页和商城均有「更换皮肤 · Petdex」，桌宠控制卡与右键菜单也可打开。
窗口内可直接浏览 Petdex；选择角色并点 ZIP 下载，导入完成后先预览，再点「换上并显示到桌面」。
也支持导入本地 ZIP 或官方资源包链接；「我的皮肤」可离线切换，一键恢复初华。
目前支持 Petdex / Codex 标准 8 列 × 9 行动态图集（包内 pet.json 与 PNG / WebP）。换肤共用原有属性、物品、回忆；初华定制配饰在其他角色上暂时隐藏。
皮肤图片保存在应用数据目录 data/pet-skins，普通 JSON 数据导出不包含皮肤图片。

新增好奇心、创造力、勇气三项属性，只涨不掉：
「口袋散步」选择路线和行动，收集 9 件小发现；好奇心 20 解锁森林，勇气 35 解锁天台。
「默契翻牌」寻找相同图案；勇气 20 后升级为六对，翻错可以继续试。
「像素手账」在 16×12 画布涂鸦并命名保存，作品册最多 12 张；创造力 20 解锁两种新画笔。
每次获得成长消耗 1 点灵感，每天最多成长 6 次；新的一天至少补到 3 点灵感，上限 9。次数用完仍可自由练习。
确认的专注记录每累计 15 分钟，好奇心 +1；单次至少 5 分钟，灵感 +1，每天最多 3 次。小游戏不增加学习时间或小鱼干，专注中需先暂停再玩。

商城与伙伴（2.7 新增）：
商城现有 23 件物品，可按点心、装扮、互动、房间分类，支持收藏和余额筛选。
点击「预览」可试穿配饰或看看房间；预览不扣款、不改变当前装扮。兑换后的配饰自动穿戴，并同步桌面初华。
八音盒、拍立得、涂鸦手账与原有玩具均可互动；亲密奖励全体玩具共用一分钟冷却。八音盒无声音，拍立得不调用真实截图。
四种房间布景应用在首页与伙伴页；桌面仍是透明悬浮角色。
选择「心愿」查看攒钱进度；现实奖励兑换后在「待兑现」打勾。伙伴页可以直接使用已拥有的玩具。
购买与兑换显示在小鱼干账本中；原有存档、余额和安静记录设置保留。

安静自动记录（默认开启）：
着陆运行时自动记录应用使用时间，切换应用或连续使用五分钟后自动结算，不再弹窗询问或弹出“已记下”的提示。
「今日 → 应用时间」查看排行；「我的 → 应用时间记录 → 整理记录」可以改名、调整分类、移除误记。
记录依赖前台窗口采样，是近似时长；电脑睡眠、关机或着陆退出期间不持续累计。手动专注避免重复记账。
采样与截屏参数可以展开调整。截屏间隔填 0 即关闭自动截屏，仍能记录时长；更新保留原有截屏设置。

界面更新：
七个页面统一配色和间距；设置分区、伙伴详情折叠、商城卡片更清楚。
输入草稿在后台刷新和切换页面时保留。弹窗可按 Escape 关闭，Tab 在弹窗内切换操作。

初华桌宠（新增）：
启动后，初华会显示在桌面右下角。点击角色收起或展开控制卡；拖动角色搬家，右键打开菜单。
可以直接开始 Python / PyTorch 的五分钟学习，暂停、继续、截屏记断点、结束并记录，或打开着陆。
输入框支持明确指令，例如“开始学 PyTorch”“暂停”“继续”“记断点”；聊天请使用着陆原有的伙伴聊天。
桌宠与主页共享真实学习计时和原养成存档；结束仍须确认实际时长。截屏会暂时隐藏桌宠和主窗口。
隐藏后，在首页伙伴卡片的齿轮里勾选“让初华住在桌面上”即可叫回；“减少动画”对桌宠同样生效。
初华使用 Petdex 作者 桜 八. 的原生逐帧动画；第三方资源出处见 _stage/assets/pet/petdex/uika/README.md。
桌宠需要着陆继续运行；彻底退出后停止。

第一次只需要做这几步：
1. 在 Python / PyTorch 卡片上点「截屏记断点」，预览画面后识别并保存；也可以点「手动记进度」。
2. 点「设置课后提醒」，勾选「开启课后提醒」并保存。
3. 点卡片下方「配置开机自启和托盘常驻」，再点「开启自启和托盘常驻」。
4. 安卓手机在系统设置中搜索「数字健康」或「健康使用手机」，为短视频、短剧应用设置时长或专注时段。电脑软件无法直接限制手机。

课后提醒：
软件读取已同步的学校课表，按当前教学周判断今天实际有哪些课，在最后一节结束后休息 30 分钟，再展示学习断点。
休息时长、备用时间和提醒星期均可调整；课表变动后请同步教务系统。
已经按你确认的作息内置：
1–2 节：08:00–09:35
3–4 节：10:05–11:40
5–6 节：13:30–15:05
7–8 节：15:35–17:10
9–10 节：18:30–20:05
11–12 节：20:35–22:10
例如：最后一课到 20:05，则默认在 20:35 提醒。
无课或缺少节次下课时间时，按设置中的备用时间提醒；休息后已过 23:00 则不再按课表提醒。
可以选择「20 分钟后提醒」或「今天休息」。软件彻底退出、电脑关机或睡眠期间无法准时提醒。

学习断点：
把课程或播放器放在着陆窗口后面；让课程标题、当前播放时间尽量露出来。
点「截屏记断点」后，着陆暂时隐藏，间隔约 0.7 秒截取两张当前屏幕画面，不读取整段视频文件。
预览里可切换画面、选择其他屏幕后重新截取。第一次截取默认选择着陆所在的屏幕。
点击「识别这两张画面」，才会发送截图到「我的 → 设置」中配置的主 AI 接口；模型需要支持图片。
识别课程/章节、当前时间、知识点和下次动作。看不清的时间会留空，需要自己补；不会猜测隐藏的进度。
确认并保存之前，所有结果都可修改，也可以不使用 AI，手动填写并保存截图。
建议填这一节的完整课程链接（HTTPS）。B 站、YouTube、Vimeo 附加时间参数，提前 5 秒开始；其他网站需手动定位。
网站是否接受跳转参数取决于播放器；更换章节请保留链接里的分 P / 章节信息。
每个学习方向保留最近 8 条断点，可在「历史断点」里恢复或删除。存档只保留小图，完整画面仅在当前识别流程中使用。
小图与文字包含在 JSON 备份里，保存在 %APPDATA%\landing；取消保存不会留下新的截图断点。
识别失败时截图和输入仍保留，可以重试或手动保存；实际识别准确度由模型与画面可读性决定。

学习：
点「接着学 5 分钟」，先把手机放远，再开始。
也可以安排每天最多三件小事，选择 5 / 15 / 25 / 50 分钟专注。
结束后确认实际专注时间，任务是否做完单独勾选。学习结束时留一句「下次先做什么」。
专注计时可以暂停，关闭到托盘后继续运行，重启也会恢复。
在活动感知开启的情况下，专注期间检测到短视频、短剧相关窗口关键词，会暂停计时并提醒。
这是基于窗口标题的粗略提醒，可能漏判或误判；不会强制关闭娱乐应用。可在课后提醒设置里关闭。

记录：
最近七天专注、每天计划和一分钟复盘都保存在本机。
历史记录入口是「翻翻之前的记录」。原来的每日必做、周报、课表和陪伴功能仍可使用。
首页伙伴改成当前角色的像素小人：头部、躯干、双臂、双腿分开运动，平时交替迈步；挥手、击掌、抱抱各有动作。原来的名字、亲密度、鱼干、喂食、聊天、养成与商店沿用同一份存档。
点角色可以摸头，按住约 0.6 秒抱抱，也可点「走两步」。专注时停止走动并捧书，暂停、完成时同步变化；「陪我读书」可单独切换，不会开始或记录学习计时。
点「有点学不动…」会给出当前 Python / PyTorch 的小步骤建议，默认台词会提及已保存的知识点；不会自动调用 AI。
右上角齿轮可设置安静、减少动画、不变饿；系统的减少动态效果也会生效。
点「喂食与养成」查看全部互动。互动有短暂成长冷却；冷却中仍会回应和做动作，但不重复增加奖励。
专注时长会同步进入原来的周报统计。

个性化技术日报（2.4）：
在「日报 → 定制我的日报」选择关注领域；可用逗号添加自己的关键词，合计最多 8 个方向。
支持按分类和文字筛选、按星标/更新时间排序、收藏和查看历史缓存。相同项目会去重。
公共 GitHub 的「近期活跃」检索近 30 天有更新且至少 30 星的项目；「新项目」检索近 90 天新建且至少 5 星的项目。语言条件只用于 GitHub 系列。
星标显示累计数量；有两次真实快照时才显示「较上次收录」的变化，不把它叫作今日涨幅。
获取失败保留上次内容；部分失败逐项提示。GitHub 查询分批进行，更新后短暂冷却，遇到服务限额按返回时间等待。
收藏与偏好在本机保存，包含在原来的 JSON 数据备份里。切换来源或兴趣不会删除原来的缓存；切回相同设置可继续查看。
可关闭「每天首次打开自动更新」，以后由你手动刷新。

私有服务：
1. 在日报定制中选择 GitHub Enterprise 或 GitLab。
2. 填 HTTPS 站点地址，例如 https://git.example.com；也可填写完整 API 根地址。GitHub Enterprise 使用 /api/v3，GitLab 使用 /api/v4，会自动补齐。支持站点子路径；localhost / 127.0.0.1 本机服务允许 HTTP。
3. 填可读取目标项目的访问令牌，再「保存并更新」。留空保留该服务令牌，也可勾选清除。
4. GitLab 内置方向匹配项目 Topic；自定义关键词搜索名称与简介，按活跃/新建时间取前 12 项，不做星标或语言过滤。Enterprise 不设最低星标要求。
日报只请求你选定的数据源，不会把私有关键词转交公共 GitHub，也不调用 AI。获取时主题和关键词会发送给所选服务；收藏可离线阅读，打开项目链接仍需要对应服务权限。
新增令牌按服务地址分别加密保存在本机 data/digest-credentials.json，不进入 JSON 备份。迁移到其他电脑需重新填写；原「我的」中的公共 GitHub Token 仍兼容原来的保存方式。
自部署服务需网络可达且证书受系统信任，不会跳过证书验证或携带令牌自动跟随重定向。
