# 学迹 · StudyTrail · 学びのあと

**2.11.0** · 记录学到哪里，让下一次开始容易一点。

StudyTrail 是一个桌面学习与陪伴应用：安排课后自学、保留课程断点、记录真实专注，并与常驻桌面的像素伙伴一起成长。支持中文、English、日本語。本版提供桌面端。

## 这次更新

- **三语言**：主界面语言选择器同步主窗口、桌宠和独立设置；用户写下的计划、昵称、记录和项目简介保持原文。AI 回复跟随界面语言。
- **商城品质**：29 件商品使用统一像素插图；重绘初华的蝴蝶结、帽子、眼镜等配饰，改善轮廓、比例和层次。
- **六种成长工具**：观察镜练好奇心，水彩盒练创造力，指南针练勇气，星图练智慧，旅行手账练默契，保温杯用于安静休息。永久工具只购买一次。
- **口袋邮局**：花园、森林、星空三条路线，每条路线有四种天气明信片。三段选择自动保存，集齐后仍可重游；水彩搭配会成为自己的邮票配色。
- **适度游玩**：与原来的探索、翻牌、画布共用灵感，每天最多六次游玩成长。工具每天首次成功可成长；邮局每天首次完成可成长。灵感不足仍能练习，游玩不增加学习时长和小鱼干。专注中先暂停再玩。

## 学习与桌宠

点击「先学 5 分钟」开始 Python / PyTorch 等方向的真实计时；课表决定课后提醒时间。点击「记断点」后才截取学习画面，可核对章节、时间点与下一步再保存。截图识别需要配置支持图片的 AI 服务。

初华以独立透明窗口停在桌面。单击展开对话，拖动移动，右键打开设置；对话 × 只收起面板。桌宠可以开始、暂停、继续学习，打开页面和记录断点。支持 Petdex 标准 8×9 动画图集换肤。游戏模式开启鼠标穿透，F7 或托盘可恢复互动。

主窗口关闭行为可在桌宠设置选择「保留桌宠，收起到托盘」。退出整个应用才停止桌宠与计时。应用时间在后台安静记录；可在「今日」查看、在「我的」整理误记。自动截屏默认关闭。

## 下载与启动

在 GitHub Releases 下载当前系统的文件：Windows x64 为 `StudyTrail-2.11.0-Windows-x64.exe`，macOS 为 DMG / ZIP，Linux 为 AppImage。Windows 完成实际桌面流程验证；macOS 与 Linux 由 CI 打包，平台特有功能仍需在对应系统确认。发布文件未进行商业代码签名。

升级继续读取原 `landing` 用户目录和 `landing.v2` 数据，保留学习记录、库存、皮肤与余额。不要删除旧用户数据目录。旧安装目录可以继续使用，应用显示名称已改为学迹。

## 本地开发

```sh
npm ci
npm run locales:build
npm start
```

```sh
npm run dist:win
npm run dist:mac
npm run dist:linux
```

界面为原生 HTML / CSS / JavaScript，桌面容器使用 Electron。翻译源在 `locales-data.tsv`，运行 `npm run locales:build` 生成运行时词典。分类标识、存储键与用户文本不能作为翻译内容。

`tools/verify-studytrail.cjs` 验证三语言、旧数据兼容、购买与成长规则、明信片、窗口同步和窄窗口布局。测试使用隔离的用户目录；可设置 `PLAYWRIGHT_MODULE`、`STUDYTRAIL_RUNTIME` 和 `STUDYTRAIL_ASAR` 指定运行环境。

数据默认保存在本机；连接 AI、教务、项目数据源或 Petdex 时，相关请求才会发送到配置的服务。导出的备份可能包含 API Key，请妥善保存。

English: StudyTrail keeps learning checkpoints, focus sessions and a desktop companion together. Change the interface language from the language selector.

日本語：学びのあと は、学習の続き・集中時間・デスクトップの仲間をまとめるアプリです。言語セレクターから表示言語を変更できます。
