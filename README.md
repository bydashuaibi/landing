# 着陆 · 把焦虑变成下一步

当前版本：**2.10.0**。桌宠采用角色常驻、单击对话、右键菜单和独立设置窗口；延用 Sage Studio 配色与原有学习、养成数据。

## 2.10 的桌宠交互与设置

- **角色留在桌面**：默认收起对话，单击展开；对话「×」与「−」均只收起对话。拖动搬家、右键菜单，显式「隐藏整个桌宠」才隐藏。
- **独立设置**：首页、伙伴页、桌宠菜单和托盘打开。设置即时保存，包括 60–160% 大小、25–100% 角色透明度、置顶、任务栏图标、锁定拖动、悬停变淡与提示。
- **游戏模式**：鼠标穿透时不触发桌宠操作，按 F7 或托盘恢复互动；恢复键占用时拒绝开启并提示。找回桌宠可移回主屏右下。
- **启动与关闭**：复用现有开机启动设置；可选择收起主窗口到托盘以保留桌宠、计时和安静记录。退出整个着陆会退出桌宠。`--pet-settings` 可直接打开设置。

## 2.9 的 Sage Studio 与桌面陪伴

- **清晰的首页**：左侧开始当前方向的五分钟学习，中间保留真实互动伙伴，右侧三张卡片展示实际进度；课程断点、计划和复盘在下方。
- **安静的视觉**：浅鼠尾草绿、深森林色、细边磨砂面板；宽屏三栏、竖屏重排、窄屏圆形导航菜单。尊重系统减少动态效果设置。
- **桌宠直接可达**：首页、伙伴与换肤窗口均可「显示到桌面」；换上皮肤同步叫出独立置顶桌宠，保存启用状态。支持 `--desktop-pet` 参数。
- **保留原有行为**：当前学习中点击主按钮回到计时，不重复创建；窄屏导航不会因后台刷新自行关闭。原有学习、皮肤与养成数据延用。

## 2.8 的换肤与小冒险

- **直接换肤**：首页、伙伴、商城和桌宠均可打开 Petdex 窗口；网站下载自动导入，也可导入本地 ZIP 或官方资源链接。先看动作，再应用到首页、伙伴页与桌宠，支持恢复初华。
- **格式与存档**：支持标准 8 列 × 9 行 PNG / WebP 动画图集，包内仅使用 JSON 和图片。皮肤单独保存在本机数据目录 `data/pet-skins`；属性、库存与回忆共用，初华定制配饰在其他角色上隐藏。
- **三个成长方向**：好奇心解锁林间散步；创造力解锁新画笔；勇气解锁六对翻牌和星光天台。属性只涨不掉。
- **三种休息玩法**：分支探索与 9 件收藏、可反复尝试的记忆配对、16×12 像素画布及 12 张作品册。
- **适度成长**：每天至少 3 点灵感，最多 6 次游玩成长；真实专注可补充灵感。用完仍能练习，游戏不增加学习时间或小鱼干，专注中先暂停再玩。

## 2.7 的商城与伙伴

- **先试再买**：点心、装扮、互动、房间分类，支持余额筛选和我的收藏；预览不会扣款或改变实际装扮。
- **买来真的能用**：新头饰同步桌宠；八音盒、拍立得、手账和原玩具触发角色动作。亲密奖励每分钟一次，八音盒不播放声音，拍立得不截取真实屏幕。
- **伙伴小屋**：晨光、雨天、星夜、森林四种布景用于首页与伙伴页；桌宠保留透明背景。
- **小小期待**：自选心愿显示攒钱进度；现实奖励继续支持兑换、待兑现与完成记录。旧道具、余额及安静记录偏好保留。

## 2.6 的安静记录与界面

应用运行时自动记录前台应用，按规则分类；无需确认，也不弹记录通知。切换应用或连续使用五分钟后自动结算，手动专注避免重复计入。采样是近似时长，不代表每一秒都在操作；睡眠和退出期间不会持续累计。

- **今日 → 应用时间**：查看应用使用排行与记录。
- **我的 → 应用时间记录 → 整理记录**：修改记录名称、分类或移除误记。
- **采样与截屏设置**：截屏间隔 0 表示关闭，仍可统计时长。新安装默认关闭自动截屏，更新保留已有设置。
- **设置面板**：启动、AI、教务、日报与备份分区；Escape 关闭弹窗，Tab 切换操作。

七个页面统一深绿色主题，伙伴详情和较少使用的功能可以展开查看；后台刷新与切换栏目会保留当前输入草稿。

## 2.5 的学习与陪伴

- **先学五分钟**：保存 Python / PyTorch 的下一步，开始真实专注计时；暂停不累计，结束后确认实际时长。
- **按课表提醒**：读取当前教学周的课表，在当天最后一节课后安排休息和自学提醒，支持调整作息和备用时间。
- **截屏记断点**：明确点击后截取两张学习画面，核对章节、时间点和下一步，再保存；配置支持图片的模型后可辅助识别。
- **初华桌宠**：独立透明悬浮窗，播放原生像素逐帧动画。点击角色展开控制、拖动搬家、右键打开菜单；主窗口收起时也能开始、暂停、继续学习和记录断点。
- **保留养成**：桌宠与主页共享原有宠物存档、互动和学习计时；支持减少动画、安静陪伴和关闭饥饿变化。
- **技术日报**：按兴趣获取 GitHub 项目，支持收藏、历史缓存、GitHub Enterprise 和 GitLab 数据源；服务令牌按地址分别加密保存在本机。

桌宠输入框支持「打开日报」「查看周报」「打开设置」「选择 PyTorch」「开始学 Python」「暂停」「继续」「记断点」等明确指令，也可直接点击页面按钮。“−”和“×”都只收起对话，角色仍留在桌面；右键「隐藏整个桌宠」后，可在首页、托盘或独立桌宠设置中叫回。

课后提醒与桌宠需要电脑开机且着陆保持运行；手机限制请使用安卓系统的专注或数字健康功能。截图识别前可预览，将使用哪些画面以及发送到哪个服务会在界面显示。

> 你不是没有方向，也不是不够努力。你只是「有想法不干事」——脑子里计划很丰满，落地为零。
> 着陆不催你做更多，它先接住你的情绪，再用 AI 帮你想清楚：今天能迈的最小一步是什么。

## 它解决什么

多线程压身（实习 / 考研 / 科研 / 比赛）的年轻人，最常见的不是「懒」，而是**空转**：
念头很多、反复权衡、焦虑打转，结果一件没动。着陆把这套断点打断：

- **倾倒台**：脑子乱时把念头倒出来，再标「可做 / 该放 / 只是情绪」，让混沌落地。
- **今天一件**：每天只承诺一件最小的、不添焦虑的事；没完成不罚，只问「明天换一件？」
- **方向罗盘**：定期对照「我以为重要的」和「实际投入的」，看见偏差，不评判。
- **情绪气象**：每天 30 秒选个天气 + 一句话，自动生成温柔的周回顾。
- **AI 陪伴**：云端 AI 真对话，不催促、不评判；「近三日跟进」一键生成日报，把你的记录变成看得见的下一步。
- **树洞**：匿名社区，说一句你今天「着陆」了什么，或还在飘着。不点赞、不评论、只看见彼此。
- **后台常驻**（桌面端）：关掉窗口只是缩到右下角托盘，程序继续跑、计时照常走；托盘悬停能看到「在计什么 / 还剩多久」，右键可彻底退出。可在「我的 → 设置」里开启开机自启（启动后直接待在托盘，不弹窗）。

## 快速开始

### 1. 纯网页（最快验证）
直接用浏览器打开 `index.html` 即可。所有数据存在本地浏览器（localStorage）。
> 想用树洞社区，需另起后端（见下）。AI 陪伴需在「设置」里填接口。

### 2. 树洞社区后端
```bash
node community-backend/server.js
# 默认 http://localhost:8787
# 然后用本地服务器打开前端，例如：npx serve .  或  python -m http.server
```

### 3. 桌面端（Electron）
```bash
npm install
npm start          # 开发预览
npm run dist       # 打包（需 electron-builder）
```

## 配置 AI 陪伴
进入「设置」，填写 **OpenAI 兼容** 接口：
- **baseUrl**：如 `https://api.openai.com/v1`
- **API Key**：你自己的 key（只存在本地浏览器，不上传）
- **模型**：如 `gpt-4o-mini`

填好后，「AI 陪伴」和「近三日跟进」即可使用。

## 技术
- 前端：`index.html` + `app.js`，零依赖、零构建、纯 `localStorage`。
- 后端（可选）：`community-backend/server.js`，零依赖 Node。
- 桌面：`Electron` 壳，GitHub Actions 跨平台构建（`dist/`）。
- 数据：全部本地优先；社区为匿名、轻量。

桌面数据目录保持为 `%APPDATA%/landing`，升级不改存档位置。个人数据、API 密钥和本地程序备份不随源码提交。
